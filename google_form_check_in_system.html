定位排查與診斷指南

為何打開權限後依然無法定位？

三大最常見無法抓到距離的原因：
  1. 手機系統定位總開關關閉（非僅瀏覽器）
  2. 位處室內/地下室，衛星訊號被遮蔽（請開啟 Wi-Fi 輔助定位）
  3. 使用 LINE / Telegram 等 App 內建瀏覽器
步驟 1：開啟系統 GPS / 位置總開關

iPhone/Windows：「設定」>「隱私權」>「位置」開啟。
Android：下拉快捷選單，將「位置資訊」圖示點亮。

步驟 2：開啟 Wi-Fi (即使沒連線)

桌上型電腦或筆電無 GPS 晶片時，開啟 Wi-Fi 能讓 Windows / Google 比對周邊熱點達成高精度定位。

步驟 3：用 Chrome / Edge 開啟

避免在 LINE 或 Telegram 內建視窗直接打卡，點選右上角選單「在預設瀏覽器開啟」最穩定。

PC 定位特點說明：
傳統有線桌上型電腦沒有 Wi-Fi 與 GPS，系統會自動切換為 IP 備援定位。IP 定位誤差較大（數公里），建議改用筆記型電腦 (開啟 Wi-Fi) 或手機進行現場打卡。
1 按 `Win + I` 開啟 Windows **設定** > **隱私權與安全性** > **位置**。
2 將 **「位置服務」** 切換為 **開啟**，並允許 Chrome / Edge 存取位置。
3 **開發者測試**：按 `F12` > 按 `Esc` 打開 Sensors 面板 > Location 選擇 Custom 輸入中友座標 (24.152422, 120.684841) 即可測試。
